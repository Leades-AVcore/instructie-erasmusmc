# instructie-erasmusmc

Interactief prototype voor een digitaal instructie- en ondersteuningsplatform voor AV-ruimtes.

## Lokaal bekijken

Start vanuit deze map een eenvoudige webserver:

```bash
python3 -m http.server 4173
```

Open daarna:

```text
http://localhost:4173
```

## GitHub Pages

Deze map is een statische website. Publiceer de inhoud van deze map naar de repository `Leades-AVcore/instructie-erasmusmc` en zet GitHub Pages op `main` met de root van de branch.
